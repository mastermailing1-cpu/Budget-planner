MASTER BUDGET PLANNER — READ-ONLY VERCEL DEMO

This is the Sample planner with read-only, non-editable controls.
All 11 pages are visible. Year/month preview and transaction month filters work.
Visitor financial edits, import, export, add, delete and reset are hidden/disabled.
Sample data is reset on page load and is never saved to localStorage.

DEPLOY:
1. Extract this ZIP into a new folder.
2. Put that folder in a GitHub repository, then import it at https://vercel.com/new .
   Alternatively use the Vercel CLI from the extracted folder: npx vercel --prod
3. Framework preset: Other. No build command needed. Root: extracted folder.
4. After deploying, open the deployment URL and check every section.

Important: This is a client-side read-only preview, NOT a secure license / DRM system.
Browser developer tools can inspect the included HTML/JavaScript and sample data.
Do not deploy the editable FULL version as a public static page if you want to restrict access.
